# Apple Music AudioGata Plugin

An AudioGata plugin for Apple Music integration using the Apple MusicKit API.

## Features

- Search for songs, albums, and artists
- Play Apple Music tracks
- Browse user playlists
- Access user's library
- Full playback control (play, pause, seek, volume)

## Setup

1. You need an Apple Developer account
2. Generate a MusicKit JWT token for your application
3. Configure the plugin with your Developer Token, App Name, and Build version
4. Authenticate with your Apple Music account

## Requirements

- Active Apple Music subscription
- Apple Developer account for MusicKit access
- Valid MusicKit developer token

## Development

```bash
npm install
npm run build
```

This will build both the plugin and options page.
